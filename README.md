Download files for ctl. products. The source repositories are private; this one only holds the built files.

| Product | Version | File |
|---|---|---|
| mder (Linux .deb) | 0.1.0 | [mder_0.1.0_amd64.deb](mder/0.1.0/mder_0.1.0_amd64.deb) |

Each version folder has a `SHA256SUMS` file. Check a download with `sha256sum -c SHA256SUMS`.

Layout: `<product>/<version>/<file>`.
